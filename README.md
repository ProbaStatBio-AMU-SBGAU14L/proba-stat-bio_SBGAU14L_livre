# Livre du cours "Probabilités et statistiques pour la biologie"

Notes détaillées pour le cours "Probalilités et statistiques pour la biologie" (SBGAU14L) enseigné dans différents Masters de biologie d'Aix-Marseille Université

1. Introduction

    - Objectifs pédagogiques
    - Logistique (matériel + logiciels)
    - Organisation du cours
    - Contenus couverts par le cours

   - Filtrage des données trop incomplètes

3. Des populations aux échantillons et retour : échantillonnage et estimation

    - Corrections de test multiple

6. Enrichissement fonctionnel : test d'indépendance

    - Rapport des cotes (Odds ratio)

    - Test khi carré ($\chi^2$) d'indépendance
    - Test exact de Fisher
    - Enrichissement fonctionnel des protéines différntiellement représentées

7. Test d'ajustement

    - Evaluation visuelle : histogrammes
